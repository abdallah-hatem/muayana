## Decisions / notes
- "Mark as sent?" is asked only when `sent` is a forward move `canMove` allows (i.e. from `assigned`); resending an
  issue already sent or further along never moves it back. Business §5.5 doesn't say; not changed there.
- Batch send passes no files (many issues' photos): wa.me with the batch text, whose photo links stand in.
- The top-bar site pill now shows on phones too (it filters the inbox); the T2 placeholder is replaced.
- Photo URLs are used as the API returns them; relative `/uploads/…` (dev) get `window.location.origin` as the
  WhatsApp link base — only correct if the web serves them.
- Visual check in the browser not done (needs the issues/workers APIs); layout follows the mockup screens 3 and 4.
