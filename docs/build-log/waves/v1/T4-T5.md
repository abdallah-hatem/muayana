# T4 + T5 — Sites, Categories, Workers API + workers CSV (+ T2 client-IP fix)
Branch `feature/t45-sites-categories-workers` (from `dev`). Agent 1, DB `muayana_t45` (dropped after).

## Built
- `apps/api/src/domains/sites` — list (`archived=false|true|all`, search name/address, paged), get, create, patch
  (rename / archive / unarchive), delete. Counts `open/new/overdue/total`. Name unique among non-archived sites via
  `nameKey`, checked in the service inside a transaction holding `pg_advisory_xact_lock(hashtext('site-name:'+key))`,
  so concurrent saves of one name can't both pass. Delete with issues → 409 `IN_USE`.
- `apps/api/src/domains/categories` — list (`active=true|all`, sortOrder), create (appended to the order, ≤100),
  patch (rename/recolour/(de)activate), `PUT /categories/order` (must be every id exactly once → else 400),
  delete (used by issue or worker → 409 `IN_USE`). Counts `open` (open issues) and `workers` (active workers).
  Duplicate `nameAr` (nameKey) → 409 `DUPLICATE`, also when the unique index wins a race (P2002 mapped).
- `apps/api/src/domains/workers` — list (search name + phone digits incl. local/Arabic-Indic, `categoryId`,
  `active` default true, paged), get, create, patch, delete, `GET /workers/export.csv` (`@RawResponse`, BOM,
  `lang=ar|en` headers, formula-guarded via shared `toCsv`, same filter as the list). Phone normalised with
  `normalizeEgyptPhone` (bad → 400) and unique (→ 409 `DUPLICATE`). Categories ≥1; unknown id → 400; inactive
  ones refused only when newly added (create, or added on patch) → 409 `INACTIVE_CATEGORY`. Counts per status +
  open + overdue. Delete with issues → 409 `IN_USE`.
- T2 fix: web `forwardToApi` (used by the proxy and the login route) sends the browser IP (first incoming
  `X-Forwarded-For`, else `X-Real-IP`) as `X-Forwarded-For`; API env `TRUST_PROXY` (default false) turns on
  Express `trust proxy`, so `@Ip()` (the rate-limit key) reads it only then.

## Notes / plan corrections
- Business decisions made (not contradicting §): category `counts.workers` counts active workers; unknown
  `categoryIds` → 400 `VALIDATION_FAILED`; worker phone in CSV gets the formula apostrophe (`'+2010…`) because
  §7's rule covers a leading `+`.
- Deploy: Vercel overwrites `X-Forwarded-For` on incoming requests. If the API is deployed behind Vercel's edge
  too, the web-set header may be replaced by the web function's IP — check at deploy (fallback: a dedicated header
  set by the web proxy, trusted only with `TRUST_PROXY`).
