## Deviations / plan notes
- **Readex Pro has no 800 weight** on Google Fonts (200–700). DESIGN.md's 800 renders as 700; `type-display`
  set to 700. DESIGN.md should say 400/500/700.
- **Site name uniqueness** is not a DB constraint (unique only among non-archived; Prisma can't express a
  partial unique index without drift). `name_key` is indexed; T4 enforces it in the service. Category
  `name_key` is a real unique index.
- **e2e guard**: agent DBs are `muayana_<name>` (no `_test` suffix, per the task); the guard refuses
  `muayana`, `muayana_template`, and anything not prefixed `muayana_`.
- No global `JwtAuthGuard` yet — T2 adds it as `APP_GUARD` (health is already `@Public()`).
- Phone input is only length-checked in `CreateWorkerRequestSchema`; T3 adds normalisation.
- shadcn primitives tuned: Button h-12 bold + press feedback, inputs h-12 / 16px / border-2, dialog
  centred with `inset-x-0 mx-auto` (the default `left-1/2 -translate-x-1/2` breaks in RTL), sheet slides
  flipped under `rtl:`, close labels translated (`common.actions.close`). The shadcn CLI wrote
  `import { cn } from "cn"` and added a bogus `cn` npm dependency; fixed and removed.
- Port 5442 collides with Prime Property's local Postgres (README notes it).
- Docs edited by someone else during the run (contract, plan, business §, decisions, `docs/design/mockup.html`)
  were left uncommitted for their owner; the only contract change (409 codes) needs no schema change.
