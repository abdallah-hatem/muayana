## Built
- **Dashboard** `apps/api/src/domains/dashboard`: `GET /dashboard?siteId` → `{ byStatus, overdue, inbox,
  byCategory, byWorker, bySite }` (shared `DashboardSchema`). Two `groupBy` queries (site × category ×
  worker × status, and the same keys for overdue) + three ref lookups — fixed query count, no N+1.
  Folding is pure (`dashboard.pure.ts` `summarize`). Archived sites excluded everywhere; `bySite` lists
  every active site in scope, even with zero counts. `inbox` = `byStatus.new`. Open = §4 open statuses.
- **Issues CSV** `GET /issues/export.csv`: `IssueFilterDto` + `columns` (comma list, validated against
  `ISSUE_EXPORT_COLUMNS`, order kept, default all in §7 order; unknown → 400) + `lang` (default `ar`).
  Streams every matching row in batches of 500 (`EXPORT_BATCH`) in list order. Cells: Cairo
  `YYYY-MM-DD HH:mm` (`formatCairoDateTime`), overdue yes/no localized (`isOverdue`), days open (Cairo
  days capture → close/now), before/after photo links (stored absolute URLs, newline-joined), last note.
- **History CSV** `GET /issues/history.csv`: every status change of the filtered issues, per site/number,
  oldest first; from/to localized.
- **Shared pieces**: `apps/api/src/common/utils/csv.util.ts` (`csvStream`, `yesNo`, `STATUS_LABELS`,
  `PRIORITY_LABELS`, `categoryName` — workers CSV now uses these), `common/decorators/csv-response.decorator.ts`
  (`@CsvResponse(filename)`, used by workers + issues), `common/dto/csv-lang.dto.ts` (`CsvLangDto`).
  `packages/shared`: `csvRow` (toCsv now built on it), `cairoDaysBetween`.
- **Overdue helper merged**: `overdueIssueWhere` (issue-counts.util) removed; sites, workers and dashboard
  use `overdueWhere` from `issue-filter.util.ts`.
- `UpdateIssueRequestSchema.categoryId` now `.nullable()` (API answers 409 on a sorted issue, §6.1); web
  callers (`details-form.tsx`, `lib/issue-endpoints.ts`) typecheck.
- Web contract matched: dashboard sends `?siteId`; export dialog sends the list filter params,
  `columns` (§7 order) and `lang` = locale; CSV header wording equals `messages/*/export.json` and status /
  priority labels equal `messages/*/common.json`.
