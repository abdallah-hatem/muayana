# T2 — Auth, app shell, seed

Branch `feature/t2-auth-shell` (from `dev`). One commit (this report included). Not pushed, not merged.

## Built
- **API auth** (`apps/api/src/domains/auth`): `POST /auth/login` (bcryptjs cost 12, JWT HS256 7 d, same 401
  `INVALID_CREDENTIALS` for wrong password and unknown email, unknown email still runs a bcrypt compare),
  `GET/PATCH /auth/me` (name trimmed 1–120, locale `ar|en`), `POST /auth/change-password` (400
  `WRONG_PASSWORD`, new ≥ 8). No register route. Passport JWT strategy (user must still exist).
- **Rate limit**: 5 failures per IP+email (email normalised) inside 15 min → 429 `TOO_MANY_REQUESTS` with
  `data.retryAfterSeconds`, checked before the password; success clears the key. `LoginAttemptStore`
  interface (`LOGIN_ATTEMPT_STORE`) with an in-memory store; injectable `CLOCK` (`common/clock`).
- **Global guard**: `JwtAuthGuard` as `APP_GUARD` (`common/guards`), `@Public()` on login + health; every
  401 is the `UNAUTHORIZED` envelope. `@GetUser()` decorator, `CurrentUser` interface.
- **Uploads**: `/uploads/*` served statically from `UPLOAD_DIR` (local driver only, outside the guard and
  the `/api/v1` prefix, no index/dotfiles, `nosniff`). `common/utils/upload-dir.util.ts`:
  `resolveUploadDir()`, `issuePhotoKey()` = `issues/<issueId>/<photoId>.jpg` (T6 reuses it).
- **Seed** (`prisma/seed.ts`, idempotent): engineer from `SEED_ENGINEER_EMAIL/PASSWORD` (created if
  missing, never overwritten), 12 categories with distinct colours (upsert by `nameKey`), and with
  `SEED_ALLOW_SAMPLE=true` (refused in production): 3 sites (1 archived), 8 workers (1 inactive, +20
  phones), 40 issues in every status (Arabic descriptions/locations, overdue + future estimates, history
  consistent with the forward path, assigned/sent/solved timestamps), 62 placeholder JPEGs (sharp) in
  `UPLOAD_DIR`; missing files are regenerated on re-run. Stable ids, so re-runs skip existing sample sites.
- **Shared**: `LOGIN_MAX_FAILURES`, `LOGIN_FAILURE_WINDOW_MINUTES`, `AuthErrorCode` in `schemas/auth.ts`.
- **e2e helper** `apps/api/test/helpers/test-app.ts`: `createTestApp()` (whole app, `FakeClock` overriding
  `CLOCK`, in-process supertest — no port), `createEngineer(t)` → `{ user, email, password, token }`
  (random password per run), `bearer()`.
- **Web**: `src/proxy.ts` (Next 16 middleware) → `lib/auth-routing.ts` (signed out → `/login?next=`,
  signed in on `/login` → `/`, expired cookie cleared, `/design` public, `/api/*` not matched so uploads are
  never buffered). Session = httpOnly cookie `muayana_session` set by `app/api/auth/login` (also sets
  `NEXT_LOCALE` from the account), cleared by `api/auth/logout` (POST) and `api/auth/signout` (GET, render
  401 hand-off). Proxy `app/api/proxy/[...path]` → `lib/api-proxy.ts` (`forwardToApi`: bearer added, cookies
  not forwarded, request body streamed with `duplex: 'half'`, response streamed with its headers minus
  encoding/length). Fetch helpers: `lib/api-server.ts` `serverFetch()` (server components),
  `lib/api-client.ts` `clientFetch()` / `clientFetchRaw()` (CSV) / `authRoute()`; `lib/api-result.ts`
  (`ApiResult`, `readEnvelope`); `lib/routes.ts` (`ROUTES`, `safeNext`, `loginUrlFor`); `lib/session.ts`
  `getMe()`.
- **Shell** (`components/shell`): `AppShell` (top bar + main + nav), `TopBar` (title slot via
  `<ShellTitle title>` override, site-switcher placeholder pill `data-slot="site-switcher"` for T8,
  language toggle, theme toggle, settings link), `BottomNav` (Dashboard · Issues · raised yellow Capture
  shutter · Inbox · Workers; side rail from md), `PlaceholderScreen`, `useSwitchLocale` (PATCH me + cookie +
  refresh). Pages: `(auth)/login`, `(app)/` + issues, capture, inbox, workers placeholders, `(app)/settings`
  (profile name, language, change password, sign out). `components/form-field.tsx` (label + asterisk +
  error). Namespaces `auth`, `shell`, `settings` (ar + en).

## Deviations / notes
- `bcryptjs` (pure-JS bcrypt) instead of native `bcrypt` — no native build on Windows/Vercel; same hashes.
- `@nestjs/jwt`/`@nestjs/passport` pinned to v11 (v12 is ESM-only and breaks Jest).
- Rate-limit IP: the web proxies login, so the API sees the web server's IP — in practice the limit is
  per email (5 wrong attempts lock the engineer out for 15 min). Forwarding the client IP needs a
  trusted-proxy decision at deploy time.
- Login 429 carries `data.retryAfterSeconds` (no `Retry-After` header: controllers don't touch `res`).
- The seed creates the engineer once and never resets its password; `db-agent template` now seeds the
  engineer + categories into `muayana_template` from `apps/api/.env`.
- Icons stay lucide (T1's choice). No business § change.
