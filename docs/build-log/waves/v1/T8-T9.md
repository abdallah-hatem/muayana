## Built
- `/settings/sites` — list (active / archived), create/edit sheet, archive/restore, delete; delete on a site with
  issues (or a 409 `IN_USE`) offers "Archive instead". Creating/renaming/archiving bumps `sitesVersion` in
  `site-context` so the top-bar switcher reloads its list.
- `/settings/categories` — list in order with move up/down (whole order sent once via `PUT /categories/order`, rolled
  back if refused), create/edit sheet with the category palette, deactivate/reactivate, delete; in use → "Deactivate
  instead".
- `/workers` — cards on mobile, table md+, search, category chips, active/deactivated tabs, pager always visible,
  Export CSV (`/workers/export.csv`, same filter, UI language) through dev's `saveResponse(res, fallbackName)`.
- `/workers/new`, `/workers/[id]` — form (category multi-select, Egyptian phone normalised to `+20…`), detail with
  call / WhatsApp, categories, issues grouped by status, `BatchSendToWorker` for his `assigned` issues, edit sheet,
  deactivate, delete (with issues → "Deactivate instead").
- Shared pieces: `components/{confirm-sheet,empty-state,issue-row,list-pager,load-error,page-header,search-field,
  segmented}.tsx`, `components/use-paged-list.ts`, `components/use-pending-action.ts`, `lib/directory-endpoints.ts`,
  `lib/category-palette.ts`; `category-chips` extended.

## Visual pass (360px + 1280px, ar + en, light + dark)
- Worker avatar in dark mode was a cream tile with a yellow letter (unreadable) → yellow tile, ink letter (mockup).
- Sub-pages set the top-bar title to the same text as their page heading (worker name twice, "Sites" twice) and a
  long name truncated the bar → removed those `ShellTitle` overrides; the bar keeps the section name, as
  `PageHeader` documents.
- Shell at 360px: section title was truncated ("العـ…") by the switcher → title keeps its width (≤40vw), the switcher
  shrinks (`w-full` on its trigger so it actually truncates instead of overlapping), and the language toggle is
  hidden below `sm` (Settings → Language has it). Touches T2's `top-bar.tsx` and `site-switcher.tsx`.
